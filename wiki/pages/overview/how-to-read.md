## Layers

Raw sources are the repository at `~/projects/persona-curvature/` (code, markdown documents, `qwen35/analysis/*.json`, `qwen35/results/*.npz`, `qwen35/phase10_runs/` logs, built pages), the old harness memory under `~/projects/agent-harness/memory/`, the `.garden/` journals, and `wiki/raw/` for material that exists nowhere else (chat extracts). Raw sources are never edited. The wiki is `wiki/pages/**/*.md`. The schema is `wiki/CLAUDE.md`.

## Conventions

- Frontmatter on every page: `title`, `summary` (one sentence, copied into the catalogue), `status`, `sources`, `last_verified`, `tags`.
- Sources are paths relative to the repository root; JSON sources carry `#dotted.key.path`. If a number's only home is a built HTML page, the page is cited and that is said.
- Statuses: current, unconfirmed, superseded, withdrawn, historical. See [[home]].
- Links are double-bracketed slugs, optionally with `|display text`. Slugs are unique across the wiki. Trait pages are `trait-<name>`, factor pages `factor-<name>`.
- Contradictions between sources are recorded on the page and in [[superseded-claims]], never silently resolved.
- No emojis. Plain short sentences. Each page stands alone.

## Hosting

The static site is built by `wiki/tools/build_site.py` into `/var/www/persona-wiki` and served by Caddy at https://wiki.161-35-77-84.sslip.io publicly (basic auth was removed at Samuel's request on 2026-09-07; to restore it, add a `basic_auth` block to the `wiki.` entry in `/etc/caddy/Caddyfile`, hash from `caddy hash-password`, and `sudo systemctl reload caddy`).

A systemd timer (`persona-wiki-build.timer`, every minute) rebuilds when any `.md` or `.py` under `wiki/` is newer than the last build, so edits made in code-server, Obsidian or a Claude session appear within about a minute. Manual rebuild:

```
cd ~/projects/persona-curvature/wiki && .venv/bin/python tools/build_site.py --force
```

The build also regenerates `index.md` from frontmatter. `log.md` is append-only and hand-written.

## Linting

```
cd ~/projects/persona-curvature/wiki && .venv/bin/python tools/lint.py
```

Reports duplicate slugs, missing frontmatter fields, bad status values, emojis, broken wikilinks and orphan pages. Run it after any batch of edits and record the pass in `log.md`.

## Obsidian

The `wiki/` directory opens directly as an Obsidian vault: wikilinks resolve, frontmatter shows as properties, and the graph view shows the hub structure. Do not let Obsidian rename files (slugs are load-bearing).

## Extending

Ingest: read the new source, write or update pages, add `sources`, append `## [YYYY-MM-DD] ingest | <source>` to `log.md`. Query: answers worth keeping are filed as pages under the nearest section and logged as `query`. Trait pages are generated by `wiki/tools/gen_trait_pages.py`; edit the generator, not the 141 pages.

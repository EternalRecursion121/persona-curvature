What the principal components are

Principal components and Big Five factor axes of 100 trait LoRA adapters, computed in weight space. Every adapter is a delta from the same base model, so the base sits at the origin and the grand mean is the direction all persona training moves.

Trait map

Each trait linked to its 5 nearest neighbours by centred cosine similarity — centring removes the shared “an adapter was trained here” direction, without which everything looks similar to everything. Positions come from the graph’s own connectivity (spectral layout), not from variance, so the edges are the data and the coordinates are only an arrangement. Filled = positively keyed, hollow = negatively keyed. Hover a trait to isolate it.

Do the weight-space factors predict behaviour?

Each weight-space factor loading against the judged shift from base to persona, on 24 behavioural probes per trait. Judging is blind to the target trait and to which checkpoint produced the text; base and stage-1 generations are interleaved as controls. A selective effect down one column means the factor encodes content; a uniform effect across all five means damage.

Assistant axis · weight space vs activation space

The base model is the origin in weight space, so the grand mean equals μ(personas) − base — the same quantity the Assistant Axis paper (arXiv:2601.10387) defines in activation space, with the sign flipped. Centering removes it, which is why the centred components below are personality axes rather than assistant-ness.

Factor solution

Principal axis factoring with SMC starts, direct oblimin rotation, on the 134-trait Gram (100 Goldberg markers + 34 Lexicon traits, the latter factored but excluded from every congruence target). Horn’s parallel analysis retains 9. Bars are coloured by each trait’s Big Five home, so a factor that mixes colours is one the model merges.

Does a nonlinear embedding help?

Leave-one-out kNN (k=5). UMAP is fitted inside each fold — fitting it on all the data and then cross-validating leaks test points into the layout. At n=100 UMAP draws clean clusters regardless of the data, so a picture is not evidence; held-out prediction is. If UMAP does not beat the linear representation, it is a drawing tool here, not an analysis.

Corpus degeneration · worst traits

Fraction of each trait’s 12,000 SFT training rows whose 5-gram repeat rate exceeds 0.3. Behavioural and corpus repetition correlate at only +0.515, and timid and shy degenerate ~75x above their (clean) corpora — so corpus damage explains some adapters and not others.
